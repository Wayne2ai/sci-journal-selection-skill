# Deliverable template

Paste-ready structure for the final recommendation.

## Lead

1. One-sentence pick (首选 + 备份 if useful).
2. Ranking mode: `Jev` or `heuristic (Jev skipped)`.
3. Preference summary: `认新锐` or `不认新锐`; Jev on/off.
4. Disclaimer line:

> 本报告不预测录用；分区/IF/Jev 仅作匹配与策略参考。

## Evidence block (top picks)

Per top journal:

- Aims URL
- Precedents: `YYYY — Title — why similar`
- LetPub page URL + access date
- What was 未核实

## Optional bands

冲刺 / 稳妥 / 保底 from `tier` or heuristic—remind once they are **strategy labels only**.

## Source footer

List date-stamped sources, e.g.:

- CAS = FQBJCR / unit mirror (year)
- XinRui + LetPub = letpub.com.cn (access date)
- 近作 = OpenAlex / Scholar / publisher
- Jev = `jev-latest` or `heuristic (Jev skipped)`
